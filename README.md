## 🛠️ 挑选 AI 中转站的“金标准”

在进入正题前，我们要明确一个好的 API 中转站应该具备哪些素质：

1.  **稳定性（Uptime）：** 如果 API 经常 502，再便宜也是浪费时间。优先选择有全球 CDN 加速的站点。🌍
2.  **模型覆盖率：** 最好能一站式调通 GPT-5.4、Claude 4.6、Gemini 3 以及国产的 DeepSeek、Kimi 等。
3.  **计费透明度：** 必须有清晰的账单系统，拒绝扣费“黑盒”。
4.  **响应速度：** 节点位置很重要，对于国内开发者，香港或新加坡的节点是首选。
5.  **客服支持：** 遇到封号或额度问题，能找到人解决。

## 💻 快速接入教程：30秒替换 API

无论你使用哪个中转站，接入方式通常都是通用的。以 [Jeniya Chat](https://jeniya.chat/) 为例，只需两步：

### 1. 获取 API Key
在后台点击“令牌/API Key”，创建一个永久有效的 Key。

### 2. 修改代码/工具配置
如果你使用的是 Python：
```python
import openai

client = openai.OpenAI(
    api_key="your_sk_key", # 填入中转站的Key
    base_url="https://api.jeniya.chat/v1" # 关键：修改为中转站地址
)

response = client.chat.completions.create(
    model="claude-3-5-sonnet-20241022",
    messages=[{"role": "user", "content": "你好，请自我介绍"}]
)
print(response.choices[0].message.content)
```

如果你使用的是 **Cursor / Readwise / NextChat**：
- **API URL:** `https://api.jeniya.chat/v1`
- **API Key:** `sk-xxxxxx`
